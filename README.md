## 🎓 Viva Questions & Answers (For Your Practical Exam)

### Q1: What architecture does Django follow?
**Answer:** Django follows the **MVT (Model-View-Template)** architecture:
- **Model**: Represents the database table and data logic (`models.py`).
- **View**: Contains business logic and processes requests (`views.py`).
- **Template**: The user interface rendered using HTML/CSS (`templates/`).

### Q2: What is the difference between `makemigrations` and `migrate`?
**Answer:**
- `makemigrations`: Inspects changes in `models.py` and creates Python migration blueprint files (inside `migrations/`).
- `migrate`: Executes SQL commands on the database to actually create or alter tables.

### Q3: What does `@login_required` do?
**Answer:** It is a Django decorator that checks if `request.user.is_authenticated`. If the user is logged in, the view executes normally. If not, Django redirects them to the URL specified by `LOGIN_URL` in `settings.py` (which is our login page).

### Q4: Why is `{% csrf_token %}` needed in forms?
**Answer:** CSRF stands for *Cross-Site Request Forgery*. The token is a unique secret generated by Django for each user session to verify that submitted POST data originates from our own legitimate form and not from an external attacker.

### Q5: What is Django ORM?
**Answer:** ORM stands for *Object-Relational Mapping*. It allows us to interact with the database using Python objects (e.g. `Toy.objects.create(...)` or `Toy.objects.all()`) instead of writing raw SQL queries.
